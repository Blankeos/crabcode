# crabcode

Cross-platform installer package for the `crabcode` CLI.

## Install

```bash
npm install -g crabcode

# or
pnpm add -g crabcode
# or
bun add -g crabcode
```

## Usage

```bash
crabcode
```

The package downloads the matching release binary from GitHub after install and
executes it on demand, so you do not need Cargo installed on consumer machines.

Repository:

https://github.com/Blankeos/crabcode
